# bins - unified bin directory repo

This is a collection of scripts I commonly use across both linux and mac. Clone
the repo to `$HOME` or wherever, and run the `common/relink.sh` script. This will
create `$HOME/bin` if needed, and symlink all common and OS specific scripts into
said `$HOME/bin` directory. Remember to add `$HOME/bin` to `$PATH` if needed.
